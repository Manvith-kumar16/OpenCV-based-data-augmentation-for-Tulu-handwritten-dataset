3. DATASET SUMMARY FOR IEEE PAPER
The Tulu Kalpuga dataset comprises a highly curated set of unique handwritten character images.
After rigorous SHA-256 validation and deduplication, 4,968 unique images across 50 classes were established.
A stratified split (Seed = 42) isolated 499 images for validation and 499 images for testing.
To combat class imbalance and enforce uniform learning, controlled data augmentation (Rotation ±15°,
Scaling 0.9-1.1, Gaussian Noise σ=10, Gaussian Blur 3x3) was applied strictly to the training split.
The final training set contains exactly 30000 images (600 per class), ensuring 0% data leakage
into the untouched validation and test sets.
